为什么是它

Duo

开合就是翻书

合上手机，外屏是皮革封面；打开手机，内屏直接出答案；快速半合再打开，就翻到下一页。不用点任何按钮。

365

一年每天一个答案

365 个原创答案，中英文双语。有肯定，有否定，也有让你停下来想一想的。翻完一轮之前不会重复。

0

不收集任何数据

不联网，不要账号，没有广告和统计。你问了什么，只有你自己知道。代码完全开源。

怎么用

  1. 合上手机，心里默念你的问题。
  2. 像翻书一样打开它。 答案已经在纸上了。
  3. 想再问一次？ 快速半合再打开，翻到下一页；或者合上，重新开始。
  4. 没有 iPhone Duo 也能用。 在其他 iPhone 上，点封面翻开，点书页翻页，向下滑合上。

开源

答案之书 Duo 的代码以 MIT 协议开源。它用的铰链手势来自同一作者的开源库 HingeKit，任何 SwiftUI app 都可以用。
